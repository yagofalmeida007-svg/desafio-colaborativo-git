Conversor de Temperaturas
Este projeto é um programa desenvolvido em Python que permite a conversão de valores entre as escalas de temperatura Celsius, Fahrenheit e Kelvin. O código foi desenhado para ser robusto, interativo e fisicamente exato.FuncionalidadesConversão Múltipla: Suporta conversões bidirecionais entre Celsius, Fahrenheit e Kelvin.Validação do Zero Absoluto: Impede a inserção de valores de temperatura que sejam inferiores ao zero absoluto (-273.15 °C, -459.67 °F, 0 K), evitando o processamento de estados termodinâmicos impossíveis.   Tratamento de Exceções: Captura e trata erros de introdução de dados (como letras em vez de números), impedindo que o programa termine de forma abrupta (crash).Menu Interativo: Interface de linha de comandos simples e intuitiva para o utilizador final.Pré-requisitosPara executar este código, é necessário ter o Python instalado no sistema (versão 3.x recomendada).Como ExecutarGuarde o código num ficheiro com a extensão .py, por exemplo, conversor.py.Abra o terminal ou a linha de comandos do seu sistema operativo.Navegue até ao diretório onde o ficheiro foi guardado.Execute o seguinte comando:Bashpython conversor.py
Estrutura do CódigoO programa utiliza um ciclo while True para manter o menu ativo até que o utilizador escolha a opção de saída (0). A lógica de validação do zero absoluto foi encapsulada na função verifica_zero_absoluto(temp, unidade_origem) para garantir a separação de responsabilidades e manter o código mais limpo e organizado.
